# 元素の帯

118 個の元素を原子番号順に一列に並べ、左右にスクロールして眺めるための周期表です。

中央の帯の上下に同じ帯のコピーを 4 本置き、**縦一列に同族の元素が並ぶ**ようにずらして追従させています。周期の長さが 2, 8, 8, 18, 18, 32, 32 と場所によって違うため、ずらす量も一定になりません。その結果、上下の帯は中央より速く流れたり、ほとんど止まったりします。この「速さの違い」がそのまま周期表の構造になっています。

**デモ:** https://numero-uno-jpn.github.io/element-strip/

## 使い方

| 操作 | 動き |
| --- | --- |
| 中央の帯をドラッグ / スワイプ | 帯が動く。指を離すとマスにスナップする |
| 矢印キー（← →） | 1 マスずつ動く |
| どの帯でもダブルクリック / 長押し | その元素が中央まで一気に移動する |

下の帯の元素を長押しすると「次の同族へ降りる」操作になります。Ne から Ar → Kr → Xe と一段ずつ下りていく、上の帯を使って族を遡る、といった読み方ができます。

## 画面の見かた

- **中央の赤いボックス** … いま選んでいる元素。5 本の帯を縦に貫いています
- **セルの背景色** … s / p / d / f のブロック。スクロールすると 2・6・10・14 の繰り返しが模様として流れます
- **上の 2 本** … ひとつ前 / ふたつ前の周期の同族
- **下の 2 本** … ひとつ後 / ふたつ後の周期の同族
- **電子配置図** … 中央の元素の殻。点の色はセルの背景色と対応していて、軌道の表記（1s² 2s² 2p⁶ …）も同じ色で書かれています

対応する元素が存在しない場所では、帯が止まります。中央が Sc から Zn へ遷移元素を 10 個進むあいだ、上の帯は Mg と Al のあいだを 1 マス進むだけです。「遷移元素の上には対応する元素がない」ことが、動かないという形で見えます。ランタノイド 14 個の区間でも同じことが起こります。

## 着想

京都大学の前野悦輝氏が考案した立体周期表 **エレメンタッチ**（Elementouch）から出発しています。エレメンタッチは元素を三重の円筒の表面にらせん状に並べたもので、第 18 族と第 1 族の断絶がなく、すべての元素が連続して並びます。

このアプリはその立体を平面に展開したもので、公式のものでも、置き換えを意図したものでもありません。立体が持つ空間的な直感は実物の模型に及びませんが、画面上での操作性と情報の出し分けは平面のほうが素直に作れます。

- エレメンタッチ公式サイト: https://ss.scphys.kyoto-u.ac.jp/elementouch/

## 技術

ライブラリもビルドも使っていません。**HTML + CSS + JavaScript の 1 ファイル**です。ダウンロードしてブラウザで開けばそのまま動きます。

```
index.html    これだけ
README.md
```

主な作りは次のとおりです。

- 中央の帯はブラウザ本来のスクロール領域（`overflow-x:auto` + `scroll-snap`）。慣性もスナップも標準機能に任せています
- 上下 4 本は `transform: translateX()` で位置を決めるだけ。スクロール量から計算して 1 行で反映します
- 同族の対応表は起動時に一度だけ作ります。対応する元素がない区間は前後の実在値から線形補間して埋めていて、これが「帯が止まる」挙動の正体です
- 電子配置は構成原理で計算し、実測とずれる 20 元素（Cr, Cu, Nb, Mo, Ru, Rh, Pd, Ag, La, Ce, Gd, Pt, Au, Ac, Th, Pa, U, Np, Cm, Lr）だけ補正しています

コードには日本語のコメントを入れてあります。

## データについて

- **ブロックの区切り** … f を La〜Yb、d を Lu〜Hg としています。こうすると原子番号が飛ばずに連続します
- **分類名** … 中央の元素の下に文字で出しています（アルカリ金属、貴ガス、ランタノイド など）。この分類ではランタノイドを La〜Lu とするため、Lu はブロックでは d、分類ではランタノイドになります。分類と電子軌道は別の切り口です
- **超重元素** … 109 番以降は化学的性質が未確定のため「不明」としています。電子配置も計算値です

## 既知の制限

- 周期 1 は H と He の 2 元素しかないため、上の帯はこの区間でほとんど動きません（仕様です）
- 電気陰性度、原子半径、イオン化エネルギーなどの数値は入っていません
- 検索窓はありません。目的の元素へはダブルクリック / 長押しで移動します
