# 元素ベルト (Element Belt)

118 個の元素を原子番号順に一列に並べた「帯」を左右にスクロールして眺める周期表アプリです。中央の帯の上下には、いま選んでいる元素と **同じ価数列** の元素が並びます。縦一列を読むと同族がそろい、たとえば **Ca の下に Zn → Sr → Cd**（すべて 2 価）が続きます。

立体周期表 **エレメンタッチ**（考案: 京都大学・前野悦輝先生）の配列に着想を得た、単一 HTML ファイルの教育用アプリです。前野先生のご了承のもとで公開しています（[エレメンタッチと引用について](#エレメンタッチと引用について)）。

**デモ:** https://medeputize.sakura.ne.jp/app/element_belt/

**提供:** EMUYN LLC（教育ブランド **EDUYN**）

## 使い方

| 操作 | 動き |
| --- | --- |
| 左右にドラッグ / スワイプ、← → キー | 原子番号順に移動する。止めると中央枠にピタッと吸い付く |
| **上下にドラッグ / スワイプ、ホイール上下、↑ ↓ キー** | **同じ価数列（同族）の中を移動する。下＝軽い側、上＝重い側** |
| どのマスでもダブルクリック / 長押し | その元素まで一気に移動する |
| 元素名・番号・記号・s/p/d/f・電子殻・電子配置をタップ（PC はホバー） | 初心者向けの解説を表示する |
| 電子配置図をタップ | 拡大表示する |
| 右上の **ⓘ** ボタン | 使い方・エレメンタッチの引用・ライセンスを表示する |

縦の操作がこのアプリの主眼です。たとえば中央を **Ba** にして下へ動かすと **Cd → Sr**（軽い 2 価）へ、上へ動かすと **Hg**（重い 2 価）へ切り替わります。

### URL で元素を指定する

URL に元素番号または元素記号を付けると、その元素を選んだ状態で開けます。

- `?z=26` / `?e=Fe` / `#Fe` … いずれも鉄（Fe）を中央に表示

## 画面の見かた

- **中央の縦のピンク帯** … いま選んでいる元素。左端にその**価数（2 価・3 価・貴ガス など）**を表示します
- **上下の関連元素** … 中央元素と同じ価数列。**上ほど軽く（原子番号が小さい）、下ほど重い**
- **縦の位置** … 「らせんの高さ」（周期＋周期内の位置）で配置しています。そのため同じ周期どうしが横一線にそろい、**周期の境目には自然な隙間**ができます
- **中央を拡大** … 画面中央に近い列ほど大きく表示します（魚眼）
- **セルの背景色** … s / p / d / f のブロック（右上の凡例）
- **上部の表示** … 元素の和名・原子番号・分類・ブロック
- **下部（フッター）の電子配置図** … 中央元素の殻。点の色はブロックの色と対応し、軌道の表記（1s² 2s² 2p⁶ …）も同じ色です

## 価数列

エレメンタッチは元素を三重の円筒にらせん状に並べたもので、**縦の列が価数（酸化数）でそろいます**。標準の周期表とは別のグループ分けになり、s+p の 8 列に d・f ブロックの両端が折り込まれます。

- **2 価列** … Be Mg Ca Sr Ba Ra ＋ Zn Cd Hg Cn　→ **Ca と Cd が同列**
- **3 価列** … B Al Ga In Tl Nh ＋ Sc Y La Lu Ac Lr　→ **Y・La・Lu が同列**
- **4 価列** … C Si Ge Sn Pb Fl ＋ Ti Zr Hf Rf ＋ Ce Th　→ **Ti と Sn が同列**
- d ブロックの中間（V〜Cu など）と f ブロックの中間（Pr〜Yb, Pa〜No）は、円筒からはみ出す独自の列になります

## 技術

ライブラリもビルドも使っていません。**HTML + CSS + JavaScript の 1 ファイル**です。ダウンロードしてブラウザで開けばそのまま動きます。

```
index.html    アプリ本体（これだけで動きます）
favicon.svg
README.md
LICENSE
```

主な作りは次のとおりです。

- **価数列モデル** … 各元素の価数列（eleCol）を求め、d・f の両端を s+p の価数列に折り込みます。これが「Ca と Cd が同列」の正体です
- **らせんの高さ配置** … 関連元素を「周期＋周期内の位置」で縦に置き、重ならないよう最小間隔を確保します
- **魚眼** … スクロール位置に応じて、画面中央に近い列を横最大 1.5 倍・縦最大 1.2 倍に拡大します
- **縦ナビ** … 縦方向の操作で価数列の隣の元素へ切り替え、画面全体をその元素の文脈に更新します
- **電子配置** … 構成原理で計算し、実測とずれる 20 元素（Cr, Cu, Nb, Mo, Ru, Rh, Pd, Ag, La, Ce, Gd, Pt, Au, Ac, Th, Pa, U, Np, Cm, Lr）だけ補正しています
- **カスタムツールチップ** … 各ラベルに初心者向けの解説を、全 118 元素には個別の特徴を表示します。ネイティブの `title` ではなく HTML で装飾した吹き出しです

アクセシビリティは[デジタル庁デザインシステム](https://design.digital.go.jp/dads/)を参考に、文字サイズ・コントラスト・キーボード操作・フォーカス表示に配慮しています。コードには日本語のコメントを入れてあります。

## データについて

- **価数列** … 標準周期表の族ではなく、価数でそろえています
- **ブロックの色分け** … ランタノイド・アクチノイド（La〜Yb, Ac〜No）を f 色にしています。色は電子軌道、列は価数で、別々の切り口です
- **分類名** … 中央元素の下に文字で出しています（アルカリ金属、貴ガス、ランタノイド など）
- **超重元素** … 109 番以降は化学的性質が未確定です。電子配置も計算値です

## 既知の制限

- 縦の同族移動は 1 つずつの即時切り替えです（なめらかなアニメーションは入れていません）
- 電気陰性度、原子半径、イオン化エネルギーなどの数値は入っていません
- 検索窓はありません。目的の元素へはダブルクリック / 長押しで移動します

## エレメンタッチと引用について

この配列は、京都大学の **前野悦輝先生** が考案された立体周期表「**エレメンタッチ（ElemenTouch）**」に着想を得ています。中央の元素と価数（他の原子との結びつきやすさ）が同じ仲間が、上下にそろって並びます。前野先生のご了承を得て公開しており、下記の論文を引用します。

> Y. Maeno, K. Hagino, T. Ishiguro,
> "Three related topics on the periodic tables of elements,"
> *Foundations of Chemistry* **23**, 201–214 (2021).
> https://doi.org/10.1007/s10698-020-09387-z （オープンアクセス）

- エレメンタッチ 公式サイト: https://ss.scphys.kyoto-u.ac.jp/elementouch/
